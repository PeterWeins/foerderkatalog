# Der Katalog – Le.pApP Förderkatalog

Ein Le.pApP-Tool für die Förderplanung (Sek I): Förderbausteine auswählen, ein Förderplan entsteht als Word-Datei, JSON oder Ausdruck.

**Direkt im Browser öffnen:** https://peterweins.github.io/foerderkatalog/

Fassung v40.0

Alle Eingaben bleiben im Browser des Geräts; es werden keine Daten an einen Server übertragen.
